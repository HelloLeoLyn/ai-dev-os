# AI Dev OS System Design

## 1. 项目目标

AI Dev OS 是一个基于 WSL2 的 AI 开发操作系统。

目标：

- AI 辅助软件开发
- 自动化测试
- 浏览器自动操作
- 多 Agent 协同
- 开发流程标准化

---

# 2. 系统组成

## 人类开发者

职责：

- 提出需求
- 确认计划
- 审核结果

---

## ChatGPT

职责：

- 架构设计
- 技术方案分析
- 问题诊断

禁止：

- 直接执行未知操作

---

## Hermes Agent

职责：

- 理解需求
- 分析任务
- 拆分步骤
- 创建执行计划

禁止：

- 未确认直接修改代码

---

## Codex Agent

职责：

- 编写代码
- 修改代码
- 重构代码
- 修复 Bug

---

## OpenClaw Agent

职责：

- 浏览器自动化
- GUI 操作
- 测试执行
- 环境操作

禁止：

- 自己改变任务目标
- 无限循环尝试

---

## MCP

提供工具能力：

- 文件访问
- Git 操作
- 浏览器控制
- 数据库访问
- API 调用

---

# 3. 核心工作流程

需求

↓

Hermes 分析

↓

生成执行计划

↓

人工确认

↓

Codex / OpenClaw 执行

↓

自动测试

↓

结果报告

---

# 4. 设计原则

所有 Agent 必须：

1. 理解任务
2. 输出计划
3. 等待确认
4. 执行任务
5. 汇报结果

禁止：

- 未授权修改
- 无限重试
- 偏离目标
