# AI Dev OS MCP Design

## 1. MCP目标

为AI Agent提供标准化工具能力。

原则：

Agent负责决策。

MCP负责执行。

---

# 2. MCP分类

## Filesystem MCP

能力：

- 读取文件
- 创建文件
- 修改文件
- 搜索代码

用途：

Codex开发。

---

## Git MCP

能力：

- 查看状态
- 创建commit
- 查看历史

用途：

版本管理。

---

## Browser MCP

能力：

- 打开浏览器
- 点击页面
- 输入内容
- 截图

用途：

自动化测试。

---

## Docker MCP

能力：

- 查看容器
- 启动服务
- 停止服务

用途：

环境管理。

---

# 3. 权限原则

默认：

只读。

需要修改：

必须授权。

危险操作：

必须人工确认。

例如：

删除文件

数据库删除

系统配置修改

---

# 4. MCP调用流程

Agent提出请求

↓

MCP检查权限

↓

执行操作

↓

返回结果

↓

Agent继续分析

---

# 5. 失败处理

MCP失败：

返回：

- 错误原因
- 环境状态
- 建议方案

禁止：

自动无限重试。
