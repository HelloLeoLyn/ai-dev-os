# AI Dev OS v1.1 Roadmap


## 目标

从 v1.0 可靠执行平台升级为可日常使用的 AI 开发操作系统。


## Phase 9 产品化


### 9-A Web Dashboard

目标：
提供 AI Dev OS 可视化管理界面。

功能：
- 系统状态
- Agent状态
- Job列表
- Execution记录
- Timeline
- Audit日志
- Recovery状态


### 9-B Task Center

目标：
统一任务入口。

流程：

User Request

↓

Task

↓

Plan

↓

Approval

↓

Execution

↓

Result


### 9-C Agent Registry

管理：
- Hermes
- Codex
- OpenClaw
- MCP

状态：
- online
- idle
- running
- error
